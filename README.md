# Excel Lookup Functions – Practice Project

## Project Overview

This project focuses on practicing Excel Lookup Functions to improve data retrieval, analytical thinking, and spreadsheet handling skills. Through hands-on exercises, I explored how lookup functions help find specific information from structured datasets efficiently.

## Functions Covered

### 1. VLOOKUP (Vertical Lookup)
Practiced retrieving information by searching for a value in the first column of a table and returning the corresponding result from another column. Explored exact and approximate matching and learned how to use VLOOKUP for vertical data searches.

### 2. HLOOKUP (Horizontal Lookup)
Practiced searching for a value in the first row of a table and returning the corresponding result from a specified row. Learned how HLOOKUP works with horizontally structured datasets and how it differs from VLOOKUP.

### 3. XLOOKUP (Extended Lookup)
Practiced using XLOOKUP to search for a value in a specified range and return a matching result from another range. Explored exact matching, custom results for missing values, and forward or reverse search options.

## Key Learning Outcomes

- Improved understanding of vertical and horizontal data retrieval.
- Practiced exact and approximate matching techniques.
- Learned to retrieve specific information from structured datasets.
- Explored how to handle missing lookup values.
- Strengthened Excel problem-solving and analytical skills.
- Gained practical experience applying lookup functions to data analysis tasks.

## Objective

The objective of this project is to build strong practical knowledge of Excel Lookup Functions and understand their application in real-world data analysis, reporting, and business operations.

This repository represents my continuous learning and hands-on practice in Excel as part of my Data Analytics skill development.
